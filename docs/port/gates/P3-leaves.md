  p3-008b ports the v10 ZIP layout and restore behaviour exactly and documents that a
  versioned archive format and pre-write backup manifest are deferred to Phase 4, where the
  SQLite backup manifest lives. This is a deferral, not a passing completeness claim.
- **Performance — empty-library-open:** **NOT MEASURED**, still deferred to Phase 4 because no
  library/database/open API exists. The Phase 2 startup/working-set proxies remain historical
  observations, not readiness or loaded-library measurements.
- **D1 — accessibility:** native Wayland accessibility remains deferred for v1; no
  end-to-end screen-reader test is claimed. X11/XWayland evidence is bounded.
- **ADR-024 single-owner exception:** review assistance is correlated and can miss shared
  blind spots. The owner selects evidence and controls merge/protection decisions. Executed
  case ratchets, frozen-source hashes, protected-path gates and CI checks are structural
  checks, not proof of semantic correctness. No independent human approval is asserted.
- **WebView:** remains deferred to v1.1 by ADR-019; no v1 browser engine.
- **p2-006-harden negative-proof logs:** the Phase 2 residual remains open; no new evidence
  is claimed here.
- **Fuzz evidence is bounded:** the main run exhausted a 45 s wall-clock budget over a fixed
  seeded corpus. It is a crash/hang/limit gate, not a coverage proof or an exhaustive parser
  correctness claim.
- **p3-006 scope:** metadata text filters and metadata/library game sorts remain deferred as
  recorded in its shard; only the stored-field boundary is claimed.
- **p3-008b limitation:** dangling-symlink mode directories remain a stated known limitation.
