## Explicit adaptation rules

* Display formatting requires a non-null `CultureInfo`, formerly `CurrentCulture`.
  The UI must pass its selected display culture. Date display also requires its captured
  `DateUiFormat` (v10 `Common/Constants.cs:15-18` captured the startup short-date pattern).
  Custom `format == null` falls back to that pattern; empty format still means the BCL
  general date/time format, not the short-date fallback.
* Relative date display receives `today` and a localization function instead of mutating
  `DateTimes`' global provider. Pass the clock's local **midnight** as v10 `Today` did.
  Existing resource keys are preserved. Release-date model overloads are deferred below.
* Description and playtime formatting receive a localization function rather than
  SDK `ResourceProvider`/WPF. No language-specific plural rules are invented: v10 selected
  existing localized templates, not a pluralization engine. Resource caching belongs to
  the future localization provider, not a pure helper.
* Parsing deliberately remains **invariant**, even for culture-sensitive display patterns:
  this preserves the v10 converter's display/parse asymmetry. `true` + null means an empty
  field; `false` + null maps WPF `UnsetValue` without introducing WPF into Core.
* `Contains` and `Replace` are explicitly static compatibility APIs: modern instance
  methods would shadow extension syntax and silently change v10 null/validation semantics.
  Ported callers needing these semantics must use `StringExtensions.Contains/Replace`.
* Unused public algorithm overloads become private implementation details. `MD5Bytes`
  is folded into its only caller, `MD5`; hex uses invariant formatting (already lowercase,
  so v10's redundant culture-sensitive `ToLower()` is removed). MD5 is a legacy cache key,
  not a security primitive.
* Goldens execute frozen source on .NET 11/Linux ICU, **not** Windows/.NET Framework.
  We preserve source semantics and pin the Linux runtime results, not Windows NLS tables.
  The oracle shims replace only clock, localization, formatting settings and WPF transport.
  Each golden includes source SHA-256s and its reproducible generator invocation.

## Pinned surprises and boundaries

`tests/golden/utils-v10.json` is generated by `scripts/port/generate_utils_goldens.py`.
It compiles the original string/enum/date source and original converter bodies in an
isolated temporary project; it never references the new Core assembly. Regenerate outside the
checkout and compare before touching the committed golden; never accept new results directly
into the oracle.
`UtilsGoldenTests.Caller_backed_helpers_match_frozen_v10_source` exercises each case.

* Null versus empty versus whitespace, trademark-only names and UTF-8 hash input. `MD5(null)`
  throws `ArgumentNullException` from the UTF-8 encoding; empty input hashes to the empty-digest
  value. `TrimEndString(null, …)` throws `NullReferenceException`, not a validated argument error.
* One suffix only; ordinal default; null receiver/value exceptions; empty suffix no-op.
* Bracket/parenthesis content retained when removing it would empty the name; `, The`
  moves to the front but `, the` does not (the initial match is case-sensitive).
* Acronyms require two alphanumeric characters and **spaces**, not arbitrary whitespace
  or punctuation, as word boundaries. Prefix acronyms are allowed.
* Legacy static `Contains(null, …)` is **true**, even with a null needle; `ContainsAny`
  on null is false. A non-null receiver with null needle/character array throws.
* Replacement validates null receiver first but returns an empty receiver before
  validating the old value; null replacement deletes; matches are non-overlapping.
* URL encoding is `HttpUtility.UrlPathEncode`, not form/query encoding: whitespace-only
  input is unchanged, plus signs stay plus signs, query strings remain unescaped.
  `System.Web.HttpUtility` is the in-box cross-platform .NET helper here, not the v10
  ASP.NET web stack; no network or hosting dependency is added. `IsHttpUrl` checks only a
  scheme prefix, so `https://` is true; `IsUri` is stricter.
* Invariant comparison options, uppercase-invariant character comparison, empty/null
  distances, integer-halved Jaro transpositions and threshold behavior.
* Dates: en-US/fr-FR/tr-TR, null/empty/whitespace, exact-width parsing, leap days,
  malformed/overflow dates, min/max years, unspecified `Kind`, invariant English month
  parsing even under French display, relative 0/1/2/6/7-day and future boundaries,
  invalid format exceptions and out-of-calendar `"unsupported"` fallback.
* Playtime: null/zero, 59/60, 3599/3600, 86399/86400, optional days, truncation of
  seconds, explicit numeric cultures, and `ulong.MaxValue` without TimeSpan overflow.
* Enum descriptions: named/unnamed numbers, named and unnamed flag combinations,
  literal/localized/no attribute. Undefined values and unnamed flags return empty,
  not the numeric value or a joined list of descriptions. Harness input uses BCL
  `Enum.Parse`, pinning case sensitivity, whitespace and overflow without adding a wrapper.

The parser additionally has 2,000 seeded calendar roundtrips and 2,000 fuzz inputs,
compared against the exact invariant BCL contract. Ambient-culture independence is
tested separately. No asynchronous work, cancellation, or disposable ownership is exposed.

| `LongExtensions.ToDateFromUnixMs/Seconds` | No production caller. |

| `DateTimes` global clock/provider and `ReleaseDate` overload; release-date converter/validation | Clock injection replaces ambient state; release model/settings dependency belongs to p3-004. This unit does not invent model or settings APIs. |
| SDK `StrExtensions.GetLocalized` | SDK localization integration belongs to p3-007; pure helpers use an explicit resolver. |
| Custom safe numeric parsing, enum parsing/flags, TimeSpan formatting/parsing, escaping, pluralization engine | No such custom extension surface exists in the frozen source. Existing callers use BCL `TryParse`, `Enum.Parse`, `HasFlag`, `Regex.Escape` or localized format strings. Do not invent wrappers. |
| `TicksToTimeSpanConverter` | WPF binding adapter returning a TimeSpan/ticks, not a formatting/parsing helper; retained for the UI port. Actual playtime avoids TimeSpan because of its narrower range. |
